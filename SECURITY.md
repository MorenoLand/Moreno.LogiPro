# Security Policy

## Supported versions

Only the latest commit on the default branch is currently supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving device writes, privilege boundaries, input injection, backup handling, or sensitive local data.

Use a private GitHub Security Advisory for this repository. Include the affected commit, operating system, build configuration, reproduction steps, and any relevant sanitized output. Do not attach device backups or HID paths unless they have been reviewed for private information.

Reports are acknowledged as soon as practical. Fix timing depends on reproducibility and hardware access.
